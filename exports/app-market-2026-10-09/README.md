# 词萤应用市场宣传图

共 12 张 PNG，按手机、平板、2in1 分成三组。打开同目录的 `index.html` 可离线浏览，切换设备分组、查看原图及单张下载。预览页无需外网依赖。

| 设备目录 | 宽高比 | 最终导出尺寸 |
| --- | --- | --- |
| `phone/` | 9:16 | 1080 × 1920 px |
| `tablet/` | 3:2 | 1920 × 1280 px |
| `2in1/` | 16:9 | 1920 × 1080 px |

每组文件顺序相同：

1. `01-home.png`：首页
2. `02-books.png`：词库
3. `03-stats.png`：统计
4. `04-profile.png`：我的

宣传视觉稿由内置 `image_gen` 生成，导出尺寸已规范化。生成提示词保存在各设备目录内的 prompts 文件中。

图中界面依据提供的截图合成，属于应用市场宣传视觉稿，并非截图的像素级原样呈现；界面细节和小字号文字可能与实际应用存在差异。原始截图未被修改。

若文件尚在生成，预览页会显示占位提示；导出完成后点击“刷新图片”即可重新载入。
