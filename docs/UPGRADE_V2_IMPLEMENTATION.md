## 重叠和冲突判定

1. **DOCX 的表结构不是迁移脚本。** 现工程已有 `word.id`、`word.word`、`review_record.response_ms` 等字段，不能照抄 `word_id`/`spelling` 新建一套孤立词库。新增属性与关系使用兼容迁移，旧数据和导入词书仍可使用。
2. **FSRS 是 DOCX 的后续规划。** 文档只给简化公式，没有完整参数、拟合过程和调度规范。当前交付仍采用可解释的间隔梯队和反应时微调；不能把经验倍率算法标为完整 FSRS。
3. **3500ms 与 4000ms 用途不同。** 3500ms 是卡片上的犹豫提示阈值；超过 4000ms 且判断认识时，使用 +8 强度和 0.8 间隔微调。连续两次模糊/不认识可展开易混辨析。
4. **音频停顿统一为 2 秒。** DOCX 为 2 秒，MD 为 1.5 秒；使用较新的 2 秒回忆窗口。发音、释义与例句必须在实际语音完成后串联，不能按示例秒数截断长句。
5. **独立拼写挑战与熟词筛选合并。** 优先挑选强度至少 75 的熟词；不足时提供实际可用的已学词。5 词/90 秒独立计分，不直接修改遗忘曲线。
6. **“4 天消化”和每日 15%–20% 并不数学等价。** 对超过 100 的队列每天按正常复习上限与 20% 释放，不承诺固定四天；界面显示本日实际释放数量，不给出固定完成天数承诺。每日新词始终按用户保存的目标安排。
7. **真题考频不能由普通语料词频替代。** ECDICT/BNC/COCA 词频或考试词书收录标签不能证明“近 10 年考研 8 次”。没有带年份、出处和授权的真题统计时，仅展示有依据的考试标签和精选核心义项，不伪造频次。
8. **补光不伪造学习历史。** 情感上的重新点亮可以使用单独的标识；不凭空为昨日插入复习次数、时间或评价事件。
9. **视觉名称以 SDK 为准。** DOCX 的 `ImmersiveMaterial` 描述不是本工程可以直接导入的 API；沿用已核实的 ArkUI/HDS API 和当前 API 26 构建基线。
10. **路线图日期不作执行约束。** DOCX 的 2025 Q1–Q3 是历史方案示意，MD 的 2026 年工程状态更贴近仓库。验收以实际构建、数据与设备行为为准。

## 系统能力的官方依据

### 系统分享与划词

官方系统分享接收方为 `ShareExtensionAbility`，配置 `ohos.want.action.sendData` 与支持的 UTD，通过 `systemShare.getSharedData(want)` 读取内容。[分享接收方开发](https://developer.huawei.com/consumer/en/doc/harmonyos-guides/share-sec-panel)

安装 SDK 的 `@ohos.selectionInput.SelectionExtensionAbility.d.ts` 与 `selectionManager.d.ts` 明确：划词扩展从 API 24 开始，设备范围为 PC/2in1；用户需在“设置→系统→智慧划词”选择划词应用；事件由鼠标/触控板选中后按 Ctrl 触发。2026-09-09 的官方指南确认支持外接键鼠的 2in1，不支持触屏选中，文本最大 6000 字节；目标应用不支持标准系统复制时划词会失效。`SelectionExtensionContext.startAbility()` 可启动本应用内 Ability。[划词服务概述](https://developer.huawei.com/consumer/cn/doc/doccenter-capabilities/selection-services-intro)

本次系统侧实现：

- `SharedWordService` 只接收并缓存待预览文本；最大 4096 字符、最多 20 个英文候选；不读取剪贴板、不在后台直接写词库。
- `WordSelectionAbility` 使用公开划词完成事件与 `getSelectionContent()`，通过本应用 `EntryAbility` 打开收词预览。
- `WordShareAbility` 与 `SharedWordPage` 是真正的系统分享接收扩展。用户确认继续后才打开主应用释义和收词确认页。
- 主应用对候选进行本地精确匹配。不存在的词不能假装有离线释义，可引导使用已有手动导入/编辑入口。

### 实况窗

官方 `TIMER` 适用于专注时刻、番茄时钟等短时间计时，**仅限工具类应用申请**，且仅支持端侧创建与更新。文档和 SDK 没有 `EDUCATION` 场景；`PROGRESS` 也不能作为教育进度的任意替代。[实况窗场景准入与受限说明](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-V13/liveview-introduction-V13)

本地实况窗必须在应用前台、用户主动开始任务后创建；更新/结束依赖进程。`isLiveViewEnabled()` 是用户开关检查，不能替代华为权益审批。[构建本地实况窗](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides-v5/liveview-create-locally-V5)

本次 `LiveStudyService` 使用真实 `startLiveView()` / `updateLiveView()` / `stopLiveView()`，TIMER 场景，系统倒计时、单调递增 sequence、串行生命周期、API 26 的 `AUTO_STOP_WHEN_APP_TERMINATE` 和有限 aliveTime。`TIMER_ENTITLEMENT_APPROVED` 默认 `false`。只有实际审批场景与签名 Profile 已生效时才可启用；关闭时核心学习正常进行。设备展示和场景审批仍需真机验证。

### 锁屏卡片

官方当前指南（2026-08-29）要求：只支持手机和平板；尺寸仅 1×1、1×2；`renderingMode` 为 `singleColor` 或 `autoColor`。必须申请锁屏卡片开放能力并使用带相应权益的签名 Profile。普通 `supportShapes: ["rect", "circle"]` 不是锁屏能力开关。[ArkTS 锁屏卡片开发指导](https://developer.huawei.com/consumer/cn/doc/doccenter-capabilities/arkts-ui-lockscreen-form-development)

本次提供 `LockScreenWordCard` 与 `lockscreen_form_config.json`：只展示单词、音标和应用名；透明前景、不展示私人的学习历史；复用共享 FormService 快照。该配置默认没有注册到模块。审批后将其中卡片项并入已注册的 `form_config.json`，使用更新签名 Profile，按真机锁屏编辑流程添加。点击 router 进入词详情是否需要解锁由系统管理，不承诺免解锁完成全部交互。

## 本次已落地的界面与数据

- 首页增加听词、5词90秒拼写、静音书桌伴读，以及21点后的晚间复盘入口；真实三分钟速学有剩余时间和结束逻辑。
- 单词卡与详情共享核心义项、搭配、可折叠词根与易混辨析；家族跳转在数据加载完成后发布，并保护学习游标。当前提供35词精选注释、8组双向易混关系，未覆盖整部词典，也没有伪造真题考频。
- 熟词复习可选先试拼写，答案揭晓后仍由用户作三档自评。独立拼写模式支持中间字母/完整单词输入和乱序字母按钮，成绩保存在独立表。
- 星图使用最近最多120个已学词的真实强度；同根掌握词连接，支持点击和可访问的单词按钮。没有持续后台粒子动画。
- 书桌伴读可选30秒、1/3/5分钟，提供暂停与常亮开关；半折叠状态只在前台首页自动进入，学习时不抢占当前任务。
- Schema 3增加犹豫与连续判断计数、注释关系、独立练习和补光。V1/V2升级使用官方Transaction，旧时间、强度和原始记录保留；备份格式升到2并包含新字段。
- 已移除忙碌程度及日常/冲刺入口；每日新词与提醒共用用户保存的目标，旧模式不再缩减新词。>100词积压按当日固定起始工作量的20%与正常复习上限释放，速学保留3/6个新词配额。未修改所有单词的长期复习日期。
- 补光在完成当天非零复习目标或超过每日新词目标5词时点亮昨日空白格，保留真实学习日和连续天数。没有将虚构活动写入历史，也没有把真实连续天数改为衰减后的分数。
- 反应时在第一次揭晓释义时截取，避免阅读搭配、词根和详情的时间被误当作回忆犹豫；历史响应记录保留原口径。
