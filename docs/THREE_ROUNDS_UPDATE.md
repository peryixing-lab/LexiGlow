# 词萤三轮更新：把学过的词，用起来

实施日期：2026-10-22 至 2026-10-23。

## 第一轮：每日学习串联

- 首页主操作区直接开始今天的学习，未完成会话可续学。原有新词目标和复习配额保持原逻辑。
- 中文自测、听写、拼写、语境填空、听词、错词本等集中到「专项练习」，保留独立选择。
- 学习结束页显示真实本轮新词与复习数量，明确本轮完成，并给出一项可跳过的练习建议。
- 优先推荐本轮模糊、不认识或犹豫的词；否则依据近七天同题型至少两次错误且尚未独立答对的词推荐。无足够证据时提供阅读入口。
- 推荐练习按指定词出题，跨词书已学词仍可进入；未学词不会加入练习。语境题缺少有效双语例句或不足四个选项时沿用明确的空状态。
- 认义、听音写词、拼写、语境逐题保存结果、提示使用、有效作答时间。每题使用稳定编号，可重试且不重复计数。保存失败时显示重试入口，阻止直接进入下一题。
- 拼写先尝试完整输入，用户主动请求后显示首尾字母和字母按钮。听音写词仍要求完整单词。
- 词详情显示每类最近最多十题的结果和提示情况。未练习明确标记；听音写词不被描述为纯听力测量。独立练习不修改间隔调度或增加每日背词完成数。

## 第二轮：我的原句

- 文章点词可收藏实际点中的句子、来源标题、段落位置和最多 500 字备注；同词可收藏不同语境。
- 重复收藏同一来源原句更新备注，不新增重复项。每词最多 100 条，全库最多 5,000 条。
- 词库增加「我的原句」，按收藏时间浏览；词详情支持查看、改备注、删除和回到原文。
- 学习卡揭晓前可以主动展开一条原句提示，并提醒按使用提示后的真实回忆判断。
- 按词的具体出现位置提取句子，保留标点；超长句保留点击处周围片段，用省略号标识截取。
- 删除来源文章后，原句与备注保留，明确显示来源已删除，取消返回链接。

## 第三轮：阅读成果体验

- 离线提供四篇原创短文：《雨天的一把伞》《给自己留十分钟》《阳台上的第一片叶子》《修好一盏旧台灯》，每篇 100–180 英文词、两道理解题及答案说明。
- 阅读库优先展示未读完、已学词形覆盖较高的短文；首页提供一篇推荐。覆盖依据实际学习记录和现有常见词形还原，不等同于阅读理解分数。
- 阅读推荐展示已学词形数、覆盖率和至多三个留意词。无学习记录也能阅读、点词和收原句。
- 按段落保存阅读位置，重新进入自动续接；从原句打开时优先定位原句段落。
- 读后题提交后显示正确答案依据，每题独立保存；全部作答后可标记阅读完成。阅读与题目不增加背词任务。
- 阅读滚动与读后答题更新各自字段，避免相互覆盖。

## 数据与兼容

- 数据库 Schema 4 → 5，新增 `practice_attempt`、`sentence_memory`、`reading_progress`；迁移在事务中执行。
- JSON 学习备份版本 4 包含新记录和用户文章，保留紧凑词典身份映射；恢复时校验单词、文章引用、唯一性、阅读位置与答案范围，再事务替换。
- v4 恢复会替换文章、原句、阅读位置和逐词练习，界面明确提示。
- v1–v3 备份仍支持恢复；保留本机原有文章、原句、阅读位置，清空不属于该备份的逐词练习记录。原有提醒设置保留规则不变。
- 系统 SQLite 备份支持 Schema 5。所有新增能力离线工作，无新增联网权限或账号依赖。

## 原生界面验收（2026-10-23）

在独立的「LexiGlow Three Rounds QA」手机模拟器（HarmonyOS API 26，1256 × 2760）使用测试数据完成：

- 首次设置 → 学习三个词 → 本轮小结 → 针对薄弱词的中文自测；答对后成功进入下一题。
- 精选短文 → 点词 → 收藏实际原句及中文备注 → 我的原句；收藏内容、出处及备注一致。
- 原句列表 → 回到原文；定位到原句所在段落。
- 两道理解题 → 逐题反馈 → 完成阅读；重新进入后仍显示 2 / 2 与完成状态。
- 重新启动应用后，原句及阅读完成记录保留，已完成短文排到未读短文之后。
- 滚动至文末 → 返回 → 再次打开；从最后一个正文段落开始续读。
- 修正阅读页和阅读库顶部内容被标题覆盖的问题，并修正列表首次布局导致的续读偏移；把「我的原句」入口移到词库顶部阅读入口旁。

### 已知边界

- 内置词典沿用当前词库；模拟器检查发现 `umbrella`、`blue` 等部分基础词未收录。点词会明确提示，未收录词暂不能绑定原句收藏。不规则变形仍不自动还原；例如 `found` 会优先匹配词典中的同形词条。后续完整基础词库和词形消歧可作为单独更新。
- 模拟器结果不替代真机音质、触觉、长时间后台使用或所有大字体/折叠设备的验收。
- 精选短文已做文字审阅与结构检查；学习效果提升仍需用户试用数据验证。
- 本轮完成本地实现、编译和验收，未提交应用市场。
